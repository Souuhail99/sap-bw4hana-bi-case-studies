# Checkliste vor der Veröffentlichung

- [ ] Ist die Veröffentlichung von Screenshots aus dem Hochschul-SAP-System erlaubt?
- [ ] Sind Matrikelnummern, Benutzernamen, Passwörter, Serveradressen, Zugangs-URLs und Tokens entfernt oder ausreichend geschützt?
- [ ] Sind die verwendeten Daten für eine öffentliche Präsentation freigegeben?
- [ ] Stimmt die README mit dem **wirklich durchgeführten** Projektumfang überein?
- [ ] Sind README und Screenshots nach dem GitHub-Upload korrekt sichtbar?
- [ ] Falls später SAP-Objektexporte ergänzt werden: Sind sie wirklich aus deinem eigenen Projekt und ohne vertrauliche Inhalte?
- [ ] Das Repo zuerst **Private** anlegen, dann prüfen und erst danach gegebenenfalls **Public** stellen.

**Nicht hochladen:** rohe Abgabe-PDFs mit Matrikelnummer, CSVs unbekannter Lizenz, SAP-Anmeldedaten, vertrauliche Systemexporte oder erfundene Quellcodedateien.
